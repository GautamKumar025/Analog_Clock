# Analog_Clock
# 🕰️ Analog Clock

A simple, real-time **Analog Clock** made with **HTML**, **CSS**, and **JavaScript**. It shows your current local time with moving hour, minute, and second hands.

---

## ✨ Features

* **Live Time:** Updates every second using your device's clock.
* **Clean Design:** Simple round clock dial that works on both mobile and desktop screens.
* **No Libraries Needed:** Built using only pure HTML, CSS, and JavaScript.

---

## 🛠️ Languages Used

* **HTML** – For the clock structure and hands.
* **CSS** – For the clock design and hand rotation.
* **JavaScript** – For calculating the current time and moving the hands.
